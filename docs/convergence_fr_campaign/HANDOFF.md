## Simulation blocks

* Job files are generated by `scripts/convergence_fr/make_jobs.py <block> [--rate R]` and launched detached and
  resumable by `scripts/convergence_fr/launch.sh <jobfile> <procs>`.
* Each run is one single-threaded process. The runner skips finished outputs and resumes from `<out>.ckpt.npz`
  (checkpoints every 10 min).
* Every launch is recorded in `results/convergence_fr_campaign/logs/launches.tsv` (time, stage, pid, procs, log).
* **Completion check:** `grep ALLDONE results/convergence_fr_campaign/logs/<stage>.log`.

```bash
bash scripts/convergence_fr/launch.sh configs/convergence_fr/jobs_E1.json 32
```

* **Blind rate calibration** (genealogy only, top-down over the frozen ladder):

```bash
/home/zheyuanlai/miniconda3/envs/abffr/bin/python scripts/overnight/fr_calibrate.py results/convergence_fr_campaign/ERIcal --K 1024
```

## Compute accounting

* `run_jobs.py` prints the cumulative core-h (wall × threads) per stage. `COMPUTE_LEDGER.md` adds them up.
* The ceiling is 200 CPU core-h aggregate over the ERI and overnight campaigns and this one.
* No GPU was used. Every GPU on the host belonged to other users at the time.
